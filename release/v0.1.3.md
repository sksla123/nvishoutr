## nvishoutr 0.1.3

### Features & Improvements
- **Startup & Shutdown Notifications**: Sends lifecycle notifications to webhooks when monitoring starts and gracefully terminates (via Ctrl+C / SIGTERM).
- **Network Retry Mechanism**: Added `notify_retry_count` and `notify_retry_delay_seconds` to prevent notification loss on temporary network blips.
- **Config Standardization**: Updated server configurations and documentation for GPU watcher targets.
