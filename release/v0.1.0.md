# nvishoutr v0.1.0

Initial release of `nvishoutr`.

`nvishoutr` is a small Rust CLI for shared NVIDIA GPU servers. It watches
selected GPUs and sends a notification when a GPU becomes available, so teams do
not need to keep polling `nvidia-smi` by hand.

## Highlights

- Watch all GPUs or a selected list such as `0,1,3`
- Notify when any watched GPU is free, or only when all watched GPUs are free
- Ignore common GUI/display processes such as `gdm`, `Xorg`, and `gnome-shell`
- Send reminder notifications while GPUs stay free
- Send a busy-again notification when a previously free GPU is taken
- Send to multiple notification destinations through shoutrrr
- Support Discord, Slack, and generic webhook notification URLs
- Preserve Discord markdown/code-block output with `splitLines=No`

## Configuration

Create a local YAML config from `cfgs/example.yaml`.

```yaml
notify_urls:
  - "discord://WEBHOOK_TOKEN@WEBHOOK_ID?splitLines=No"
notify_when: "any"
notify_busy_again: true
poll_interval_seconds: 60
reminder_interval_minutes: 30
notification_title: "GPU free"
nvidia_smi: "nvidia-smi"

ignore:
  process_patterns: []
  graphics_users: []
```

Real configs often contain webhook tokens, so only `cfgs/example.yaml` should be
committed.

## Run

```bash
nvishoutr --config cfgs/my-server.yaml --gpus all
nvishoutr --config cfgs/my-server.yaml --gpus 0,1,3
nvishoutr --config cfgs/my-server.yaml --gpus 0 --dry-run
```
